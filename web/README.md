# Caesar Cipher — Live Web Demo

This folder contains the browser-based live-demo version of the B.Y.T.E Task 1 project.

## Run locally

Open `index.html` directly in a browser, or serve the folder with a local web server.

## Deployment

This folder is designed as a static web application and can be deployed on Vercel or Netlify.

No backend or environment variables are required.

## Privacy

All encryption and decryption are performed locally in the browser. The entered message is not sent to a server.
